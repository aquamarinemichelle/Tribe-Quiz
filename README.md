# Tribe Quiz

A web-based quiz game covering the cultures of Africa.  
Live : https://african-quiz.onrender.com

## Question Categories Used
- Language
- History
- Tradition
- Culture
- Music
- Food
- Geography
- Notable People

## Planned Features
- [ ] Timer per question
- [ ] Sound effects (drum on correct answer)
- [ ] High score leaderboard (localStorage)
- [ ] Questions displayed in the chosen language (e.g. IsiZulu)
- [ ] Difficulty levels (Easy / Medium / Hard)
